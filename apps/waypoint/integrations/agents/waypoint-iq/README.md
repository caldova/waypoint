# WaypointIQ integration

WaypointIQ is the curated agent-facing OpenAPI/toolbox contract over Waypoint.
It is not an agent.

This directory retains app-side integration assets. The canonical contract and
guide live under
[`modules/agents/waypoint-iq`](../../../../../modules/agents/waypoint-iq/README.md)
and
[`modules/agents/docs/WAYPOINTIQ.md`](../../../../../modules/agents/docs/WAYPOINTIQ.md).

Deployment supplies the current endpoint and credentials. Do not hardcode
environment-specific toolbox versions, app IDs, or service URLs.
